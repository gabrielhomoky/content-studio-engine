# Caption rules

```
{HOOK LINE: mirrors or complements the on-screen hook; the first ~125 characters show in feed}

{1-4 short lines of value or story: line breaks, not a wall of text}

{ONE CTA matched to the goal: comment a word / save / send / follow / enquire}

{3-6 relevant hashtags}
```

## Three variants per script

- **A · curiosity**: opens a loop the video closes.
- **B · value stack**: what they will get / learn (good for saves).
- **C · story**: a short personal, first-person angle in the client's own voice. For a
  storytelling designer this can run longer (5-10 lines) and is often her strongest format:
  specific, honest, a little self-ironic, ending with a light question or CTA.

## Rules

- Hook in the first line. One CTA, not three.
- Instagram search reads captions: include 1-2 natural keywords people actually search
  ("small apartment design", "green hallway", "дизайн інтерʼєру {місто}"). No keyword stuffing.
- Hashtags: 3-6, a mix of 1-2 broad niche tags and 2-4 specific topic/location tags. No
  #viral #fyp spam.
- Write in the script's language only. Ukrainian: natural modern Ukrainian (not a calque of
  English, not Russian vocabulary). English: clean, warm, international.
- No em dashes (—) anywhere in client copy. Emojis sparingly (0-2), only if the client uses
  them.
- Never paste a competitor's caption; rewrite the structure only.
- Location posts: tagging the city/neighbourhood helps local discovery when relevant to the client's markets.
